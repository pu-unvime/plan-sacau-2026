# Documentación del Plan de Estudios

Este sitio reúne los tres documentos de la carrera **Programador Universitario de Sistemas**. La navegación sigue los encabezados de los originales y permite leer cada sección de forma independiente.

## Cómo recorrer el plan

Utilice el menú lateral para acceder a las secciones y la tabla de contenidos para navegar dentro de cada página. Los enlaces **Anterior** y **Siguiente** mantienen el orden de lectura de los documentos.

La búsqueda funciona localmente, sin enviar consultas a servicios externos. También puede cambiar entre el tema claro y oscuro.

:::info Fuentes documentales
Los documentos originales se conservan sin modificaciones. El enlace **Editar esta página** abre el archivo fuente correspondiente en GitHub. Las páginas de los anexos y sus índices se regeneran automáticamente al construir el sitio.
:::
